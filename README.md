## ⚡ Visão Geral

📱 VirtualSIM - Plataforma e Dashboard de Gerenciamento de Números Virtuais e SMS. Desenvolvido com foco em alta performance, usabilidade moderna e arquitetura web escalável.

### 🌟 Principais Recursos:
* Dashboard intuitivo para acompanhamento de linhas
* Simulação de recebimento de SMS e tokens
* Histórico e logs de ativação em tempo real
* PWA responsivo para dispositivos móveis

## 💻 Stack Tecnológica

* **Arquitetura:** Progressive Web App (PWA), Service Workers
